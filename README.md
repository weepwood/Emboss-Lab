# Emboss Lab — 浮雕海报交互网页

根据五张视觉参考重新绘制的单页网页 Demo：渐变纸张、凹刻文字、线条压印、微颗粒纸纹、鼠标漫反射聚光与五组独立 SVG 画面。

## 运行

1. 解压整个目录，保留 `index.html`、`assets/interface.css` 和 `assets/grain.svg` 相对路径。
2. 双击 `index.html`，在现代浏览器中打开即可，完全不需要服务器、安装依赖或联网。
3. 若需要本地服务器，可在此目录执行：`python -m http.server 8000`，打开 `http://localhost:8000`。

## 操作

- 左侧检查器（移动端在下方）切换 5 种海报；右侧大画布实时显示调整结果。参数区独立滚动，底部常驻常用操作和导出。
- 「材质调整」分为 **压印 / 光照 / 着色 / 画面** 四组，可折叠：
  - 压印：浮雕深度、边缘柔度、**压印方向、轮廓强度**、颗粒密度、颗粒尺寸、**纸纹混合模式**。
  - 光照：漫反射强度、光斑半径、**高光颜色**、跟随指针开关、手动光源位置。
  - 着色：纸面颜色、着色强度、混合模式（柔光 / 叠加 / 正片叠底 / 滤色）。
  - 画面：缩放、**旋转**、暗角、亮度、对比、饱和度。
- 「柔和 / 标准 / 锐利」预设一键套用整套材质参数，也可随时点「恢复默认」。
- 左侧固定操作区提供随机切换、明暗主题、沉浸模式、**复制链接**和 **PNG 导出**（1000 / 1676 / 2400 px 宽度）。
- 左侧品牌栏「快捷键」按钮（或按 `?`）打开快捷键浮层；`←/→`、`1`–`5`、`R` 随机、`T` 主题、`F` 沉浸、`Esc` 退出。
- 参数与主题保存在 `localStorage`；URL 参数优先，可分享链接。
- 将鼠标移到海报上，光斑跟随指针；关闭「跟随指针」后用滑块定位光源。

## 技术实现

- **纸张**：多层 `radial-gradient` 和 `linear-gradient` 叠加。
- **颗粒**：SVG feTurbulence 灰度噪声覆盖，混合模式可在柔光、叠加、正片叠底及正常之间切换。
- **压印**：SVG 矢量路径和文字，两组相反方向的 `drop-shadow` 呈现反光与暗边；支持自由调整方向、深度和轮廓宽度。
- **光照**：鼠标位置驱动 CSS 自定义属性，移动 `radial-gradient` 高光；也支持固定光源。
- **着色与画面**：`mix-blend-mode` 着色层、暗角层与 `filter` 滤镜链，均由侧栏参数驱动。
- **分享与导出**：URL 参数序列化非默认设置；导出时把当前 SVG 画面栅格化为 PNG（渐变纸面为近似重绘）。
- **字体与图标**：ADSTRONAUT 标题为自绘几何矢量字形；界面使用系统字体与内联 Lucide 风格 SVG 图标；无外部字体或 JavaScript 依赖。
- **界面主题**：`assets/interface.css` 使用语义 Design Tokens 管理浅色和深色工作台；艺术画面样式保留在 `index.html`，不会受主题切换影响。
- **可访问性**：键盘切换、焦点可见、`prefers-reduced-motion` 支持。

该 Demo 是独立的视觉复现，不包含原图本身，所有压印形状均为网页中可修改的矢量元素。原图包含更细腻的材质物理细节；网页实现是实时渲染的设计近似，而不是逐像素 1:1 复制。
## 设计规范

参见 [DESIGN.md](DESIGN.md)：界面色彩、排版、间距、状态与交互原则。工作台采用中性的编辑器布局，避免用大面积装饰效果干扰海报本身。

## 部署到 GitHub Pages

本项目是零构建的静态网页。公开仓库可以在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存后即可通过 GitHub Pages 访问。

GitHub 仓库：https://github.com/weepwood/Emboss-Lab

> PNG 导出基于渐变背景与 SVG 浮雕图层重绘；目前不包含 CSS 纸纹、光斑、暗角等后处理叠加层。输出尺寸不随页面缩放改变。
